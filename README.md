# tvty-egui screenshots

Screenshots for the issues of the tvty-egui experiment (tvty's window
rebuilt on egui-pop, see `docs/EGUI.md` on the experiment's branch): the
GPUI window and the egui-pop one side by side, the differences framed in
red and numbered. Made by `egui/scripts/compare.py` from wbox captures at
1280x800. This branch holds images only; it shares no history with the
code.
